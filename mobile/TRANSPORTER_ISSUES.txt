Transporter / App Store Connect — current issues
================================================

What you saw
------------
1) ERROR 90174 — Missing Provisioning Profile
   "Apps must contain a provisioning profile in a file named embedded.mobileprovision."

2) No app icon in Transporter
   Placeholder App Store “A” icon while verification fails / unsigned IPA.

3) No App Store description
   Description lives in App Store Connect listing, not inside the .ipa.


Why Transporter rejects the GitHub Nexus.ipa
--------------------------------------------
GitHub Actions builds an UNSIGNED Sideloadly IPA on purpose
(CODE_SIGNING_ALLOWED=NO). That package never contains:

  • embedded.mobileprovision  (App Store Distribution profile)
  • valid Apple Distribution code signature

Matching the bundle ID (hu.qyopy.nexus.B44X8B76QR) is required but NOT enough.
Transporter will always fail 90174 on the Sideloadly IPA.


How to upload correctly (Mac + Xcode)
------------------------------------
1. Open https://nexusproject.cc (or this repo) on your Mac.
2. In Terminal:

     cd mobile
     npm i
     npx cap add ios   # first time only
     npx cap sync ios
     npx cap open ios

3. In Xcode → App target → Signing & Capabilities
   • Team: BARBARA EVA CSATTOS / owner@qyopy.hu
   • Bundle Identifier: hu.qyopy.nexus.B44X8B76QR
   • Automatically manage signing

4. Product → Archive → Distribute App → App Store Connect → Upload

That signed archive embeds the provisioning profile + icons properly.
