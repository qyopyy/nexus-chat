Transporter / App Store Connect — issues & fix (no local Xcode)
===============================================================

Issues you hit
--------------
1) ERROR 90174 — Missing Provisioning Profile
   Unsigned Sideloadly IPA has no embedded.mobileprovision.

2) No icon in Transporter
   Placeholder while verification fails; marketing icon must be opaque RGB.

3) No App Store description
   Description is edited in App Store Connect (see app-store-listing.txt).

4) Xcode “not compatible” on your Mac
   Current Xcode needs a newer macOS. You do NOT need Xcode locally.


Fix: sign + upload on GitHub’s Mac (cloud)
-----------------------------------------
Follow:  mobile/APP_STORE_CI_SETUP.txt

Workflow:  Actions → “iOS App Store (signed)”

That produces a real App Store IPA with:
  • embedded.mobileprovision
  • Apple Distribution signature
  • opaque App Store icons

Then either:
  • upload=true in the workflow (API key), or
  • download Nexus-AppStore.ipa and drop it into Transporter


Do NOT upload
-------------
GitHub releases named “Nexus iOS build N” / Sideloadly Nexus.ipa
→ always 90174.
